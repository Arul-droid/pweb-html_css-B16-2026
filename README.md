# Website Profil Prabowo Subianto

Website profil sederhana yang dibuat untuk **Praktikum Modul 1**. Website ini menampilkan informasi mengenai **Prabowo Subianto** dalam bentuk halaman profil dan Curriculum Vitae (CV).

## 📌 Deskripsi

Website ini dibuat menggunakan **HTML dan CSS** dengan konsep desain sederhana, modern, dan responsif.

Terdapat dua halaman utama:

* **Home** — menampilkan profil singkat, perjalanan pengabdian, serta program.
* **CV** — menampilkan profil, pendidikan, pengalaman, dan informasi terkait Prabowo Subianto.

## ✨ Fitur Website

### 1. Navigation Bar

Website memiliki navigation bar untuk berpindah antar halaman dan bagian website.

Menu yang tersedia:

* Home
* Pengabdian
* Program
* CV

### 2. Hero Section

Halaman Home memiliki bagian pembuka yang menampilkan:

* Nama Prabowo Subianto
* Deskripsi singkat
* Foto
* Tombol menuju halaman CV

### 3. Pilar Pengabdian

Menampilkan tiga bidang perjalanan karier:

* Militer & Pertahanan
* Kepemimpinan Politik
* Pemerintahan

### 4. Karya & Program

Menampilkan beberapa program yang berkaitan dengan pemerintahan, seperti:

* Makan Bergizi Gratis (MBG)
* Cek Kesehatan Gratis (CKG)

### 5. Curriculum Vitae

Halaman CV berisi beberapa bagian:

* Profile
* Education
* Experience

### 6. Hover Effect

Website menggunakan efek `hover` pada beberapa elemen seperti tombol, navigation, dan card untuk membuat tampilan lebih interaktif.

### 7. Responsive Design

Website menggunakan **CSS Media Query** agar tampilan dapat menyesuaikan dengan ukuran layar desktop, tablet, maupun smartphone.

## 🎨 Konsep Desain

Website menggunakan kombinasi warna:

* Hitam
* Putih
* Abu-abu
* Gold

Desain dibuat sederhana dengan fokus pada keterbacaan informasi dan tampilan yang rapi.

## 🚀 Cara Menjalankan Website

1. Clone repository:

```bash
git clone <URL-REPOSITORY>
```

2. Masuk ke folder project:

```bash
cd modul1
```

3. Buka file:

```text
index.html
```

di browser.

Website dapat dijalankan tanpa web server karena menggunakan HTML dan CSS sederhana.
